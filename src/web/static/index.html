Ajax Spider 선택 사항 사용 안 함

브라우저로 버튼을 눌러 JavaScript가 만드는 요청까지 수집합니다. 일반 수집보다 오래 걸립니다. 선택하지 않으면 사용하지 않습니다.

현재 헤더·파라미터 이름에 공격 값을 넣는 기능은 없어서, 입력이 헤더나 이름에 있는 요청은 수집되어도 공격 대상이 되지 않습니다.

기본은 끔입니다. 끄면 페이지에 미리 채워진 값을 씁니다. 켜면 무작위 값 때문에 기준 요청부터 서버 오류가 날 수 있습니다.

Ajax Spider를 사용할 때만 설정할 수 있습니다. 삭제·로그아웃 등 위험한 링크·버튼은 자동으로 누르지 않습니다. (60~18000초, 최대 5시간)
